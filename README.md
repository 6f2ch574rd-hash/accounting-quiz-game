# 會計學段考題庫遊戲（CH1–6）

把段考習題與課堂講授整理成的複習網頁，單一檔案、無需伺服器，手機／電腦開瀏覽器即可玩。

## 玩法

- **選擇題闖關**：126 題選擇（含是非 66 題），答對得分、連對有 Combo，附完整詳解
- **簡答翻字卡**：47 題簡答，點擊翻面看答案，邊翻邊記
- **計算題抽選**：51 題抽題，依章節熟練度加權（練得少的單元更容易被抽中），抽到可對照 PDF 解答
- **五點熟練度自評**：每單元自評 1–5 星，送出後系統主動推送「練得最少」的單元給你複習
- **全範圍／單章節切換**：可一次複習 CH1–6，也可只練某一個章節
- **詳解總覽**：寫完題目可一次瀏覽全部詳解（內嵌於頁面，非彈跳小視窗）

## 題庫規模

| 章節 | 題數 |
|---|---|
| 第一章 會計基本概念 | 40 |
| 第二章 借貸法則與會計程序 | 60 |
| 第三章 調整及編製財務報表 | 30 |
| 第四章 結帳與財務報表 | 22 |
| 第五章 現金 | 33 |
| 第六章 買賣業會計 | 39 |
| **合計** | **224** |

第六章為課本作業 p.126–132（問答 8、是非 10、選擇 10、計算 11），答案依解答本 p.37–44。

## 檔案

- `index.html` — 遊戲主程式（題庫內嵌，單檔即可執行）
- `會計學段考題庫.json` — 題庫資料檔（224 題）
- `會計學_計算題解答圖表.pdf` — 計算題報表式解答（遊戲內可開啟）

## 題源標記

- **解答本**：題目與答案出自習題解答本照片（第一權威）
- **AI 解析**：解答本未印解析，由 AI 依題義補寫，開頭固定標「〔AI 解析：解答本未印〕」
- **待核對**：解答或部份內容尚未核實，遊戲中標記為待核對、不計分
