# 會計學段考題庫遊戲（CH1–6）

把段考習題與課堂講授整理成的複習網頁，單一檔案、無需伺服器，手機／電腦開瀏覽器即可玩。

## 玩法

- **選擇題闖關**：128 題選擇（含是非），答對得分、連對有 Combo，附完整詳解
- **簡答翻字卡**：48 題簡答，點擊翻面看答案，邊翻邊記
- **計算題抽選**：40 題抽題，依章節熟練度加權（練得少的單元更容易被抽中），抽到可對照 PDF 解答
- **五點熟練度自評**：每單元自評 1–5 星，送出後系統主動推送「練得最少」的單元給你複習
- **全範圍／單章節切換**：可一次複習 CH1–6，也可只練某一個章節
- **詳解總覽**：寫完題目可一次瀏覽全部詳解（內嵌於頁面，非彈跳小視窗）

## 檔案

- `index.html` — 遊戲主程式（題庫內嵌，單檔即可執行）
- `會計學段考題庫.json` — 題庫資料檔（216 題）
- `會計學_計算題解答圖表.pdf` — 計算題報表式解答（遊戲內可開啟）

## 題源標記

- **解答本**：題目與答案出自習題解答本照片
- **AI 解析**：解答本未印，由 AI 依題義解析
- **課堂講授**：依課堂錄音整理的概念題（第六章），待課本內容補件後覆核
- **待核對**：解答或部份內容尚未核實，遊戲中標記為待核對、不計分
