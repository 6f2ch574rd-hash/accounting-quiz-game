# 會計學段考題庫遊戲（CH1–4）

把 CH1–4 段考習題做成的複習網頁，單一檔案、無需伺服器，手機／電腦開瀏覽器即可玩。

## 玩法

- **選擇題闖關**：86 題選擇（含是非），答對得分、連對有 Combo，附完整詳解
- **簡答翻字卡**：33 題簡答，點擊翻面看答案，邊翻邊記
- **計算題抽選**：33 題抽題，依章節熟練度加權（練得少的單元更容易被抽中），抽到可對照 PDF 解答
- **五點熟練度自評**：每單元自評 1–5 星，送出後系統主動推送「練得最少」的單元給你複習
- **全範圍／單章節切換**：可一次複習 CH1–4，也可只練某一個章節
- **詳解總覽**：寫完題目可一次瀏覽全部詳解（內嵌於頁面，非彈跳小視窗）

## 檔案

- `index.html` — 遊戲主程式（題庫內嵌，單檔即可執行）
- `會計學段考題庫.json` — 題庫資料檔（152 題）
- `會計學_計算題解答圖表.pdf` — 計算題報表式解答（33 頁，遊戲內可開啟）
